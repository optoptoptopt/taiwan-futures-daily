# 台指期每日盤後籌碼與正逆價差 CSV

臺灣期貨交易所、臺灣證券交易所開放資料整理成的每日 CSV，**每個交易日晚上自動更新**，免費使用。

網頁版（含圖表、每日重點）：<https://acaiprotocol.com/chips/>

## 檔案

| 檔案 | 內容 | 起始 |
|---|---|---|
| [`data/chips_daily.csv`](data/chips_daily.csv) | 每日籌碼摘要：大台近月結算與未平倉；外資／投信／自營台指期淨未平倉；外資買權、賣權淨未平倉；十大交易人中特定法人的台指近月淨部位；小台、微台散戶多空比；P/C 未平倉比；最近月選未平倉最多的履約價 | 2026-05 |
| [`data/basis_daily.csv`](data/basis_daily.csv) | 每日正逆價差：加權指數收盤、近月與次月收盤、收盤價差、近月 13:30 對齊價差 | 2024-10 |

- 編碼 UTF-8（含 BOM），Excel 直接開啟中文不會亂碼。
- 一個交易日一列，依日期由舊到新。空白代表當天沒有該項資料。
- `basis_daily.csv` 的 13:30 對齊價差從 2026-08-21 才有：期交所逐筆成交檔只保留 30 個交易日，開始抓之前的日子補不回來。
- 月選履約價取「還沒到期的最近月選」中未平倉最多的價位；遠月合約上市時指數較低，偶爾會出現離現價很遠的履約價，那是實際資料。

### 直接用程式讀

```python
import pandas as pd
url = "https://raw.githubusercontent.com/optoptoptopt/taiwan-futures-daily/main/data/chips_daily.csv"
df = pd.read_csv(url, encoding="utf-8-sig")
```

## 欄位定義

- **散戶多空比**：(全市場未平倉 − 三大法人多單) 減 (全市場未平倉 − 三大法人空單)，再除以全市場未平倉。
- **十大特定法人台指近月淨部位**：期交所「前十大交易人」中特定法人的近月買方減賣方，台指期為大台＋小台÷4。
- **13:30 對齊價差**：近月台指期 13:30:00 以前最後一筆成交價，減加權指數收盤。收盤價差（13:45 對 13:30）有 15 分鐘時差，單日可能差幾十點。
- 計算方式跟網站一致，說明見 <https://acaiprotocol.com/basis>。
